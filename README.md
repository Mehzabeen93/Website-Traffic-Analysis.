# Website Traffic Analysis Dashboard

## Project Overview
This project focuses on analyzing website traffic to understand visitor behaviour, traffic sources, device usage, conversion rates, and page performance.

I used Python for data analysis and developed an interactive dashboard using Streamlit and Plotly to present the results.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib & Seaborn
- Plotly
- Streamlit
- Jupyter Notebook

## Dataset
The dataset contains 2,000 website sessions with information about users, traffic sources, devices, session duration, pages visited, bounce rates, and conversions.

## Dashboard Features
- Total sessions and unique users
- Bounce rate and conversion rate
- Traffic source and device analysis
- Average session duration and pages per session
- Monthly traffic and conversion trends
- Website page performance
- Interactive filters

## Key Findings
- Organic search generated the highest number of sessions.
- Direct traffic had the highest conversion rate.
- Mobile devices generated the most sessions.
- Desktop users had a higher conversion rate than mobile users.
- Website page performance varied across different metrics.

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run app.py
```

## Conclusion
This project helped me apply Python and data analysis skills to a practical dataset and develop an interactive dashboard to turn website traffic data into meaningful insights.
